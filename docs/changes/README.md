# Change requests

One file per request, `CR-<nnn>-<slug>.md`, created with the `change-request` lifecycle command from
the template in `.claude/skills/salon-sdlc/assets/change-request.md`. The process is in
`.claude/skills/salon-sdlc/references/change-requests.md`.

A change request is how a requirement is added, changed or retired after the BRD baseline, and how
a suggestion from a QA review reaches the owner. None has been raised yet.
